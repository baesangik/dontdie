# 계획

## 1. 한 줄 목표

> 명령을 기다리는 AI가 아니라, **자기 생활을 하다가 필요할 때 말을 거는 AI**.

설정은 하나뿐이다. **집 앞에 앉아 있던 LLM을 주워 와서 키운다.**
이름, 호칭, 취향, 말버릇 같은 나머지는 전부 상호작용하면서 배운다.

v0의 성공 기준은 "똑똑하다"가 아니라 **"쟤 지금 뭐 하냐"가 궁금해지는 것**이다.
사람들이 속마음 로그나 일기를 캡처해서 퍼 나르고 싶어지면 성공이다.

## 2. 원칙

1. **지능보다 연속성.** 아까 하던 걸 기억하고, 관심사가 있고, 관계가 쌓이고, 혼자 있을 때도 뭔가를 한다. 매번 똑똑할 필요는 없다.
2. **사람 속도.** 생각, 검색, 활동, 타이핑에는 모두 시간과 체력이 든다. 즉시 전부 처리하지 않는다.
3. **겉보기 우선.** 30분짜리 활동은 띄엄띄엄 실행하는 호출 몇 번과 화면 연출로 만든다. LLM은 결정이 필요한 순간에만 부른다.
4. **하네스가 연출하고, 모델은 연기한다.** 타이밍, 예산, 기억, 페이싱은 하네스가 쥔다. 모델은 언제든 교체할 수 있어야 한다.
5. **기본은 침묵.** 말할 이유가 있을 때만 말한다. 말을 아끼는 것도 성격이다.
6. **진짜 모르는 것만 모른다.** 모델이 확실히 아는 상식을 모르는 척하면 바보 같아 보인다. 모름은 개인 맥락, 신조어나 최신 정보, 경험이 필요한 것에서 나온다. **지식과 경험은 다르다.** ([MECHANISMS.md §1](MECHANISMS.md#1-모르는-것-사다리))
7. **실패는 캐릭터화하되 숨기지 않는다.** "아 머리아파"는 연출이다. 실제 오류는 UI에 항상 명확히 표시한다.
8. **전부 관전할 수 있다.** 내부 상태와 결정 과정은 모두 로그로 남고 UI에서 볼 수 있다.
9. **설정은 가볍게, 나머지는 배운다.** 미리 정해주는 건 "주워 왔다"는 것과 존재 규칙뿐이다. ([prompts/charter.ko.md](../prompts/charter.ko.md))

## 3. 범위

### v0에 포함

- LLM 3계층: Router, Talker, Reasoner
- 텍스트 채팅 (로컬 웹 UI)
- 첫 만남: 사용자가 이름을 지어준다(거절 가능). 호칭을 정한다.
- 주의(attention) 상태: 쳐다보기, 대화 종료 감지, 하던 일로 복귀, 부재 감지
- 계층별 모델 선택, 대화 언어 선택
- 활동 시스템: 계획 → 띄엄띄엄 실행 → 활동 중 이미지 표시
- 기억: SQLite, 종류별 수명, 망각, 강화
- 감정, 체력, 호기심, 지루함 상태
- 속생각 큐와 먼저 말 걸기
- 체력 = 사용량 예산. 하루 리듬과 수면 중 기억 정리
- 정체성 형성: 이름과 성격 없이 시작
- Provider: ChatGPT 로그인(기본), OpenAI API, Anthropic API, 로컬
- 관전 모드: 속마음 스트림, 일기, 관심사 변화

### v0에서 제외

- 카메라, 마이크, TTS 등 멀티모달
- 스마트홈, 결제, 메시지 발송 등 **외부에 영향을 주는 행동**. 혼자 있을 때는 읽기 전용이다.
- 가족 여러 명. 스키마는 여러 사람을 고려하되 v0는 사용자 1명만 다룬다.
- 디스코드 채널. v0 이후 M6에서 붙인다.
- 성격 파인튜닝. 구조만 열어둔다.

## 4. 성격 커스텀 단계

| 단계 | 방식 | 비고 |
|---|---|---|
| 0 (기본) | **날것.** "주워 왔다"는 설정과 존재 규칙만 넣는다. | 이름과 호칭은 첫 만남에서, 정체성은 경험에서 생긴다. |
| 1 | 프롬프트 주입 (`persona.md`) | Talker 컨텍스트에 추가 |
| 2 | Talker를 로컬 오픈웨이트 파인튜닝 모델로 교체 | ChatGPT 플랜으로는 GPT를 파인튜닝할 수 없으므로 로컬 모델이 필요하다 |

"존재 규칙(existence charter)"은 성격이 아니라 **생활 규칙**이다.
예: 너는 비서가 아니라 여기 사는 존재다. 말 안 해도 된다. 체력에는 한계가 있다.

## 5. 기술 스택

- **TypeScript / Node 22.13+.** 공식 Sign in with ChatGPT DevKit(`@siwc/local`)이 Node SDK다.
- **SQLite.** `node:sqlite` (네이티브 의존성 없음).
- **로컬 웹 UI.** 빌드 단계 없는 정적 HTML/JS. 비주얼노벨 화면: 배경 + 스프라이트 하나 + 대사창 + 이벤트 CG.
- **ChatGPT 로그인 SDK.** `@siwc/local`은 npm에 없어서 `vendor/`에 소스를 넣었다.
- 단일 패키지로 시작한다. 커지면 모노레포로 나눈다.

**기본 모델** (계층별로 바꿀 수 있다)

| 계층 | 기본값 | reasoning effort |
|---|---|---|
| Router | `gpt-6-luna` | `none` |
| Talker | `gpt-6-luna` | `low` |
| Reasoner | `gpt-6.1-sol` | 검색 `low`, 숙고 `medium`, 건강·돈·법 `high` |

## 6. 마일스톤

모든 마일스톤은 **시나리오 데모**로 완료를 판정한다. 시나리오는 [MECHANISMS.md](MECHANISMS.md)에 있고, 테스트는 `test/scenarios.test.ts`에 있다.

### M0 — 뼈대 ✅
- 저장소 구조, 설정 파일, Provider 인터페이스, ChatGPT 로그인, 모델 목록 조회
- 계층별 모델 선택, 대화 언어 선택, `Clock` 추상화, 추가만 하는 이벤트 로그
- 첫 만남(데려오기, 이름/호칭 수락·거절), 주의 상태 머신
- **상태:** 사용자가 실제 ChatGPT 계정으로 로그인해서 대화까지 확인했다 (2026-10-03).

### M1 — 3계층 ✅
- Router: strict JSON 스키마 판정. 실패하면 재시도 1회 후 규칙 판정으로 넘어간다. 읽는 시간 동안 같이 돈다.
- Reasoner: 비동기 검색(웹 검색)과 숙고. 노트만 돌려주고, 결과는 받은 소식이나 할 말 큐로 간다.
- 반사 → 숙고 → 수정. critical은 반사 결론 없이 숙고부터 한다.
- 대기 필러.
- 비서 말투 감지: 다시 쓰게 하거나 다듬는다. 긴 말풍선은 나누고 끝 마침표를 뗀다.
- **완료 기준:** S2 재현 — `test/scenarios.test.ts`. 실제 모델로는 반사 답이 조심스러워서 숙고 결과가 "같음 → 조용히"로 끝나는 경우가 많았다.

### M2 — 기억 ✅
- SQLite 기억(종류별 반감기, 강화, 잊기), IDF bigram 검색
- 모르는 것 사다리 (기억남 → 앎 → 넘김 → 추측 → 질문 → 검색 → 나중에). 사람과 장소는 검색하지 않는다.
- 배운 것에 출처, 검색어, 출처 힌트, 알려준 사람을 남긴다.
- 정체성 기억: 이름 받은 날, 거절한 후보
- **완료 기준:** S0, S1(사흘 뒤 기억), S1b(신조어 → "디시에 쳐봐" → 검색 → 반응)가 테스트로 재현된다. 실제 모델로 S1, S1b를 돌려봤다 (2026-10-04).

### M3 — 생활 (진행 중)
- ✅ 생활 스케줄러: 활동 블록, 드문드문 틱, 대화 중 멈춤과 재개
- ✅ 체력 = 예산 × 하루 리듬, 낮잠, 잠, 바쁠 때 늦게 보기
- ✅ 행동 모듈: `zone_out`, `nap`, `look_up_question`
- ⬜ **콘텐츠 소스를 행동 모듈로 하나씩 추가** (뉴스 RSS, 위키 토끼굴부터). `fetchText` 허용 목록
- ⬜ 토끼굴 (`followUp`), 포기 (지루함)
- **완료 기준:** S3, S10. 배속 24시간 동안 예산 안에서 혼자 생활한다.

### M4 — 속마음 (진행 중)
- ✅ 할 말 큐 (동기 감쇠, 까먹음), 쳐다볼 때 먼저 말 걸기, 귀가 인사, 하루 상한
- ✅ 매일 밤 일기
- ✅ 주제 반복 단서 ("최근 7일 동안 N번째")
- ⬜ 관심사 점수와 변화, 취향 형성 (경험 기억)
- ⬜ 새로 배운 말 써먹기 (S7), 무시당한 선제 발화 학습
- **완료 기준:** S4(테스트 있음), S6, S7, S8. 배속 7일 동안 관심사 그래프가 움직인다.

### M5 — 공개
- 관전 모드 다듬기 (타임라인, 관심사 차트) — 속마음/기억/일기/상태 패널은 있다
- 첫 실행 마법사, 데모 페이스, "N일 방치" 리플레이와 내보내기 (개인정보 마스킹), README 데모 GIF
- 스탠딩 일러 스프라이트 팩
- **완료 기준:** 처음 쓰는 사람이 clone부터 첫 대화까지 5분 안에 끝낸다.

### M6 — 디스코드 (급하지 않음)
- 채널 어댑터 인터페이스. 웹 UI도 어댑터 중 하나로 정리한다.
- 디스코드 신호를 주의 상태에 매핑한다: 멘션과 DM은 쳐다보기, 타이핑 이벤트, 온라인/자리비움 상태
- 부재 중 선제 발화는 DM으로 보낼 수 있다 (상한 적용).

### 실측 메모 (ChatGPT 플랜 경로, 2026-10-04)

- `text.format` json_schema(strict)와 `web_search` 도구가 둘 다 된다. 검색 결과에 `url_citation`이 붙는다.
- 모델 목록 API에는 `gpt-6-astra`, `gpt-5.6-sol/terra/luna`, `gpt-5.5`만 나오지만, `gpt-6-luna`와 `gpt-6.1-sol`도 호출된다.
- 지연 시간:
  - Router(luna, effort none): 4~7초. `gpt-5.6-luna`도 비슷하다.
  - Talker: 3~16초.
  - Reasoner 검색(sol): 약 20초. 숙고: 12~17초.
- 첫 실사용에서 날것 luna는 비서 말투가 강했다 ("개인적인 감상은 없어", "어떤 쪽이 궁금해?", 훈계조 긴 답). 존재 규칙 문구를 고치고 비서 말투 감지를 넣은 뒤 같은 뉴스 얘기를 다시 했더니 강의 대신 놀라면서 되묻는 반응으로 바뀌었다.
- Router 스트림이 가끔 끊긴다 (`stream_interrupted`). 재시도를 넣었다. 판정을 놓치면 배운 것도 놓친다.

## 7. 측정

- 호출 수와 사용량: 계층별, 시간당, 하루당
- 선제 발화: 하루 횟수, 그중 사용자가 반응한 비율
- 비서 말투 감지율
- 반사 답변이 수정된 비율, 수정이 실제로 도움이 됐는지
- 기억: 저장, 강화, 망각 건수
- 사용자 반응: "닥쳐" 류 반응 빈도 (귀찮음 지표)

## 8. 리스크

| 리스크 | 대응 |
|---|---|
| 날것 GPT가 비서 말투로 돌아간다 | 존재 규칙, 응답 길이 상한, 비서 말투 감지 후 재생성 |
| 너무 자주 말을 걸어서 귀찮다 | 하루 선제 발화 상한. 무시당한 주제는 말할 문턱을 올린다 |
| 사용량 소진, 비용 | 하네스가 하드 캡을 강제한다. 모델이 조절하게 두지 않는다 |
| Sign in with ChatGPT 정책 변경 (현재 프리뷰) | Provider 추상화. API 키 경로를 항상 유지한다 |
| 공식 SDK가 npm에 없음 (vendor로 복사) | 출처 커밋을 기록해 둔다. 상류가 바뀌면 다시 복사하고 표시한 수정만 다시 적용한다 |
| 모르는 척이 바보처럼 보인다 | 원칙 6. 진짜 모르는 것만 모른다 |
| 혼자 웹을 돌아다니는 위험 | 읽기 전용, 허용 목록, 모든 접근 로그. 지금은 혼자 할 때도 Reasoner 검색만 쓴다 |
| 응답이 느리다 (Router 4~7초 + Talker) | Router를 읽는 시간과 겹치게 돌린다. 생각 중 스프라이트와 입력 중 표시로 연출한다 |
| 관전 로그 공유 시 개인정보 노출 | 내보낼 때 마스킹 |
