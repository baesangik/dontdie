# 계획

## 1. 한 줄 목표

> 명령을 기다리는 AI가 아니라, **자기 생활을 하다가 필요할 때 말을 거는 AI**.

v0의 성공 기준은 "똑똑하다"가 아니라 **"쟤 지금 뭐 하냐"가 궁금해지는 것**이다.
사람들이 속마음 로그나 일기를 캡처해서 퍼 나르고 싶어지면 성공이다.

## 2. 원칙

1. **지능보다 연속성.** 아까 하던 걸 기억하고, 관심사가 있고, 관계가 쌓이고, 혼자 있을 때도 뭔가를 한다. 매번 똑똑할 필요는 없다.
2. **사람 속도.** 생각, 검색, 활동, 타이핑에는 모두 시간과 체력이 든다. 즉시 전부 처리하지 않는다.
3. **겉보기 우선.** 30분짜리 활동은 띄엄띄엄 실행하는 호출 몇 번과 화면 연출로 만든다. LLM은 결정이 필요한 순간에만 부른다.
4. **하네스가 연출하고, 모델은 연기한다.** 타이밍, 예산, 기억, 페이싱은 하네스가 쥔다. 모델은 언제든 교체할 수 있어야 한다.
5. **기본은 침묵.** 말할 이유가 있을 때만 말한다. 말을 아끼는 것도 성격이다.
6. **진짜 모르는 것만 모른다.** 모델이 확실히 아는 상식을 모르는 척하면 바보 같아 보인다. 모름은 개인 맥락, 신조어나 최신 정보, 경험이 필요한 것에서 나온다. **지식과 경험은 다르다.** ([MECHANISMS.md §1](MECHANISMS.md#1-모르는-것-사다리))
7. **실패는 캐릭터화하되 숨기지 않는다.** "아 머리아파"는 연출이다. 실제 오류는 UI에 항상 명확히 표시한다.
8. **전부 관전할 수 있다.** 내부 상태와 결정 과정은 모두 로그로 남고 UI에서 볼 수 있다.

## 3. 범위

### v0에 포함

- LLM 3계층: Router, Talker, Reasoner
- 텍스트 채팅 (로컬 웹 UI)
- 활동 시스템: 계획 → 띄엄띄엄 실행 → 활동 중 이미지 표시
- 기억: SQLite, 종류별 수명, 망각, 강화
- 감정, 체력, 호기심, 지루함 상태
- 속생각 큐와 먼저 말 걸기
- 체력 = 사용량 예산. 하루 리듬과 수면 중 기억 정리
- 정체성 형성: 이름과 성격 없이 시작
- Provider: ChatGPT 로그인(기본), OpenAI API, Anthropic API, 로컬
- 관전 모드: 속마음 스트림, 일기, 관심사 변화

### v0에서 제외

- 카메라, 마이크, TTS 등 멀티모달
- 스마트홈, 결제, 메시지 발송 등 **외부에 영향을 주는 행동**. 혼자 있을 때는 읽기 전용이다.
- 가족 여러 명. 스키마는 여러 사람을 고려하되 v0는 사용자 1명만 다룬다.
- 성격 파인튜닝. 구조만 열어둔다.

## 4. 성격 커스텀 단계

| 단계 | 방식 | 비고 |
|---|---|---|
| 0 (기본) | **날것.** 존재 규칙만 넣는다. | 정체성은 경험에서 생긴다. |
| 1 | 프롬프트 주입 (`persona.md`) | Talker 컨텍스트에 추가 |
| 2 | Talker를 로컬 오픈웨이트 파인튜닝 모델로 교체 | ChatGPT 플랜으로는 GPT를 파인튜닝할 수 없으므로 로컬 모델이 필요하다 |

"존재 규칙(existence charter)"은 성격이 아니라 **생활 규칙**이다.
예: 너는 비서가 아니라 여기 사는 존재다. 말 안 해도 된다. 체력에는 한계가 있다.

## 5. 기술 스택 (제안)

- **TypeScript / Node 22+.** 공식 Sign in with ChatGPT DevKit(`@siwc/local`)이 Node SDK다.
- **SQLite.** `node:sqlite` 또는 `better-sqlite3`.
- **로컬 웹 UI.** Vite + React. 로그인 버튼에 `@siwc/react`를 쓸 수 있다.
- 단일 패키지로 시작한다. 커지면 모노레포로 나눈다.

## 6. 마일스톤

모든 마일스톤은 **시나리오 데모**로 완료를 판정한다. 시나리오는 [MECHANISMS.md](MECHANISMS.md)에 있다.

### M0 — 뼈대
- 저장소 구조, 설정 파일, Provider 인터페이스
- ChatGPT 로그인, 로그인한 계정의 모델 목록 조회
- Talker 단독 채팅 (CLI → 웹)
- `Clock` 추상화 (실시간 / 배속)
- 추가만 하는 이벤트 로그
- **완료 기준:** 로그인 후 대화가 되고, 모든 호출이 이벤트 로그에 남는다.

### M1 — 3계층
- Router 출력 스키마(JSON)와 규칙 기반 대체 구현(테스트용)
- Reasoner 비동기 작업, Talker 받은편지함(inbox)
- 반사 → 숙고 → 수정
- 대기 필러("잠깐 찾는 중")
- 비서 말투 감지
- **완료 기준:** 시나리오 S2(회사 때려칠까)가 재현된다.

### M2 — 기억
- 종류별 SQLite 테이블, 검색, 강화, 망각
- 모르는 것 사다리 (무시 → 추측 → 질문 → 검색 → 숙고)
- 배운 것에 출처와 알려준 사람 기록
- **완료 기준:** S1(모르는 사람 이름), S1b(신조어 → "검색해봐")가 재현된다. 사흘 뒤(배속)에도 기억한다.

### M3 — 생활
- 활동 블록: 계획 → 드문드문 틱 → 결과
- 활동별 스프라이트, 상태 줄
- 자유시간 활동 선택기
- 체력 = 예산. 하루 리듬, 수면, 낮잠, 멍때리기
- 바쁠 때 "잠깐 이것만"
- **완료 기준:** 30분 활동이 실제 호출 4~6회로 돌아간다. 배속 24시간 동안 예산 안에서 혼자 생활한다.

### M4 — 속마음
- 속생각 → 할 말 큐 → 동기 점수 → 발화 또는 망각
- 귀가 인사 ("나 아까 ~ 하다가 ~에 빠졌음")
- 매일 밤 일기
- 관심사 변화, 정체성 형성 (이름, 취향, 의견)
- 반복 감지 ("또 그거?")
- **완료 기준:** S4(귀가), S6(반복), S7(새로 배운 말 써먹기)이 재현된다. 배속 7일 동안 관심사 그래프가 움직인다.

### M5 — 공개
- 관전 모드 UI 다듬기 (속마음 스트림, 타임라인, 관심사 차트, 잊힌 기억 목록)
- 첫 실행 마법사: 로그인 → 모델 선택 → 예산 설정
- 데모 페이스 (빠른 진행)
- "N일 방치" 리플레이와 내보내기 (개인정보 마스킹)
- README 데모 GIF
- **완료 기준:** 처음 쓰는 사람이 clone부터 첫 대화까지 5분 안에 끝낸다.

## 7. 측정

- 호출 수와 사용량: 계층별, 시간당, 하루당
- 선제 발화: 하루 횟수, 그중 사용자가 반응한 비율
- 비서 말투 감지율
- 반사 답변이 수정된 비율, 수정이 실제로 도움이 됐는지
- 기억: 저장, 강화, 망각 건수
- 사용자 반응: "닥쳐" 류 반응 빈도 (귀찮음 지표)

## 8. 리스크

| 리스크 | 대응 |
|---|---|
| 날것 GPT가 비서 말투로 돌아간다 | 존재 규칙, 응답 길이 상한, 비서 말투 감지 후 재생성 |
| 너무 자주 말을 걸어서 귀찮다 | 하루 선제 발화 상한. 무시당한 주제는 말할 문턱을 올린다 |
| 사용량 소진, 비용 | 하네스가 하드 캡을 강제한다. 모델이 조절하게 두지 않는다 |
| Sign in with ChatGPT 정책 변경 (현재 프리뷰) | Provider 추상화. API 키 경로를 항상 유지한다 |
| 모르는 척이 바보처럼 보인다 | 원칙 6. 진짜 모르는 것만 모른다 |
| 혼자 웹을 돌아다니는 위험 | 읽기 전용, 허용 목록, 모든 접근 로그 |
| 관전 로그 공유 시 개인정보 노출 | 내보낼 때 마스킹 |

## 9. 미정 사항

- [ ] 외부 공개 이름
- [ ] 자아 이름: 정해서 줄지, 본인이 정하게 둘지 (현재 방향은 후자)
- [ ] 라이선스. `@siwc/local` DevKit은 **비상업 라이선스**다. 프로젝트 라이선스를 정할 때 같이 고려해야 한다.
- [ ] Reasoner 웹 검색 경로. ChatGPT 플랜 사용 시 Responses API의 `web_search` 지원 여부를 확인하지 못했다. 안 되면 자체 검색 도구(SearXNG, 검색 API + 본문 추출)를 쓴다.
- [ ] Router 모델: 클라우드 경량 모델, 로컬 소형 모델, 규칙 중 무엇으로 할지. 지연과 비용을 측정해서 정한다.
- [ ] 혼자 놀 때 읽을 콘텐츠 소스: 뉴스 RSS, 위키, 커뮤니티(읽기 전용) 등. 사이트 약관과 robots.txt를 지킨다.
- [ ] 사용자 부재 감지 (텍스트만 있을 때): 마지막 메시지, 창 포커스, "나갔다 올게" 같은 명시
- [ ] 채널: 로컬 웹 UI만 할지, 디스코드나 텔레그램도 붙일지
- [ ] 언어: 한국어 우선으로 할지, 처음부터 다국어로 할지
