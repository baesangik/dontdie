# dontdie

> **코드명**입니다. 외부 공개 이름은 미정입니다. 캐릭터 이름은 **처음 데려온 사용자가 지어줍니다** (거절당할 수도 있습니다).

집 앞에 앉아 있던 LLM을 주워 와서 키우는 하네스입니다.

명령을 기다리는 챗봇이 아니라, **PC 안에서 자기 생활을 하다가 필요할 때 말을 거는 AI**를 만듭니다.

```
git clone → ChatGPT로 로그인 → 비 오는 밤, 현관 앞에 앉아 있던 걸 데려옴
→ 이름 지어줌 (거절당할 수 있음) → 모르는 건 물어보고, "검색해봐" 하면 찾아보고,
  혼자 있을 땐 궁금했던 걸 찾아보고, 밤에는 자고 일기 씀
```

설정은 "주워 왔다"는 것뿐입니다. 이름, 호칭, 취향, 말버릇 같은 나머지는 **상호작용하면서 배워 나갑니다.**

목표는 똑똑한 비서가 아니라 **자연스러운 생각의 과정**입니다.
모르는 단어가 나오면 바로 검색하지 않고 먼저 물어봅니다. "아니 이걸 몰라? 디시에 쳐봐" 하면 그제서야 찾아봅니다.

## 상태

**M2까지 구현, M3·M4 일부.** 실제 ChatGPT 계정(`gpt-6-luna` / `gpt-6.1-sol`)으로 아래 흐름을 돌려봤습니다.

- **3계층**: Router(무의식)가 매 메시지를 JSON으로 판정합니다. Talker(자아)가 말하고, Reasoner(외장 뇌)가 뒤에서 검색하거나 고민합니다.
- **모르는 것 사다리**: 기억남 → 앎 → 넘김 → 추측 → 질문 → 검색 → 나중에.
  - 사람 이름은 검색하지 않고 물어봅니다. 배운 건 출처, 날짜, 알려준 사람과 함께 기억합니다.
- **반사 → 숙고 → 수정**: 중요한 고민에는 일단 직감대로 답하고 뒤에서 다시 생각합니다.
  - 결론이 바뀌면 "……아 근데" 하고 고쳐 말합니다. 대화가 이미 넘어갔으면 나중에 말할 거리로 미뤄 둡니다.
  - 건강·돈·법 문제는 섣불리 결론 내지 않습니다.
- **기억**: SQLite에 종류별 수명을 두고 저장합니다. 꺼내 쓰면 강해지고, 약해지면 잊습니다(지우지 않고 '잊힌 기억'으로 남깁니다).
- **감정·체력**: 기분이 흔들렸다가 돌아옵니다. 체력은 하루 호출 예산에 하루 리듬을 곱한 값입니다.
- **비서 말투 감지**: "어떤 쪽이 궁금해?", "개인적인 감상은 없어" 같은 말투가 걸리면 다시 쓰게 하고, 긴 말풍선은 나눕니다.
- **혼자 생활**: 멍때리기, 낮잠, 궁금했던 거 찾아보기를 합니다. 밤에는 자면서 기억을 정리하고 일기를 씁니다.
- **할 말 큐**: 하고 싶은 말을 쌓아 둡니다. 쳐다볼 때나 돌아왔을 때 먼저 말을 걸고, 오래 못 하면 잊습니다.

다음은 콘텐츠 소스(뉴스, 위키 …)를 행동 모듈로 하나씩 붙이는 것입니다. → [docs/PLAN.md](docs/PLAN.md)

## 실행

Node.js 22.13 이상이 필요합니다.

```bash
git clone https://github.com/baesangik/dontdie.git
cd dontdie
npm install
npm start
```

터미널에 뜨는 주소(`http://127.0.0.1:7717`)를 브라우저로 열면 첫 만남 장면이 나옵니다. 데려오려고 하면 **Sign in with ChatGPT**를 하라고 합니다.

- ChatGPT 로그인 정보는 OS 키링에 둔 키로 암호화해서 `data/`에 저장합니다. Linux는 Secret Service(gnome-keyring, KWallet)가 필요합니다.
- 실제 모델 없이 화면만 둘러보려면: `DONTDIE_FAKE=1 npm start`
- 실제 모델로 대화 몇 마디를 돌리고 내부(Router 판정, 사다리, 검색, 기억)를 터미널에서 보려면:
  `npm run try -- "너 이름 뭐야?" "이거 완전 킹리적갓심이네" "아니 이걸 몰라? 디시에 쳐봐"`
- 다른 Provider: 설정에서 계층별로 고릅니다. OpenAI API는 `OPENAI_API_KEY`, Claude는 `ANTHROPIC_API_KEY` 환경 변수를 씁니다.
- 테스트: `npm test`, 타입 검사: `npm run typecheck`

## 화면

비주얼노벨처럼 생겼습니다. 방 배경에 스프라이트 하나가 서 있고, 표정과 하는 일에 따라 그림을 바꿔 끼웁니다.

- 첫 만남은 이벤트 CG로 나옵니다 (비 오는 밤, 현관 앞).
- 대사창, 백로그(로그), **속마음 패널**(관전 모드)이 있습니다.
  - 속마음 패널에서는 Router 판정, 사다리 단계, 검색, 배운 것과 잊은 것, 할 말 큐, 기억 목록, 일기, 기분과 체력을 전부 볼 수 있습니다.
- 지금 그림은 "원에 눈 단" 땜빵입니다. 스탠딩 일러는 [web/sprites/README.md](web/sprites/README.md) 형식으로 팩을 만들어 넣으면 됩니다.

## 핵심 아이디어

- **LLM 3계층**
  - **Router(무의식)**: 가장 가벼운 모델. 판정만 하고 말하지 않습니다. 실패하면 규칙 판정으로 넘어갑니다.
  - **Talker(자아)**: 본체. 말투와 결정을 맡고, 모델 크기는 상관없습니다.
  - **Reasoner(외장 뇌)**: 검색과 고민을 맡습니다. 말투 없는 노트만 돌려주고, Talker가 그걸 자기 말로 바꿉니다.
- **판정과 타이밍은 하네스가, 말은 Talker가**: 언제 말할지, 뭘 기억할지, 검색할지는 하네스가 정합니다. 모델은 언제든 바꿀 수 있습니다.
- **사람 속도**: 읽는 시간, 입력 중 표시, 말풍선 나누기를 지킵니다. 생각, 검색, 활동에는 모두 시간과 체력이 듭니다.
- **겉보기 우선**: "궁금했던 거 찾아보는 중 (3/8분)"은 실제로는 호출 한 번에 화면 연출을 더한 것입니다.
- **주의(attention)**: 채팅창을 누르면 쳐다봅니다. 대화가 끝난 것 같고 15초 동안 말이 없으면 하던 일로 돌아갑니다.
- **기본은 침묵**: 말할 이유가 있을 때만 말합니다.

## 모델

계층마다 Provider와 모델을 따로 고를 수 있습니다. 기본값은 다음과 같습니다.

| 계층 | 기본 모델 | 비고 |
|---|---|---|
| Router | `gpt-6-luna` | reasoning effort `none`, JSON 스키마 출력 |
| Talker | `gpt-6-luna` | reasoning effort `low` |
| Reasoner | `gpt-6.1-sol` | 검색은 effort `low` + 웹 검색, 고민은 `medium` (건강·돈·법은 `high`) |

| Provider | 인증 | 비고 |
|---|---|---|
| ChatGPT (기본) | Sign in with ChatGPT | 사용자의 ChatGPT 플랜 사용량을 씁니다. 오픈소스/로컬 앱용 프리뷰입니다. 웹 검색과 JSON 스키마 출력이 됩니다. |
| OpenAI API | API 키 | |
| Anthropic (Claude) | API 키 | Claude 구독(Pro/Max) 로그인은 서드파티 앱에서 허용되지 않아 **API 키만** 지원합니다. |
| 로컬 (OpenAI 호환) | 없음 | Ollama, llama.cpp, vLLM 등. 파인튜닝한 Talker를 쓸 때 필요합니다. 웹 검색은 없습니다. |
